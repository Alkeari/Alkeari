# Alkeari

Free game mods, tools and browser extensions. Everything I publish stays free for everyone.

Every project, release and store link lives on [alkeari.com](https://alkeari.com). Releases: [alkeari.com/releases](https://alkeari.com/releases/). Roadmap: [alkeari.com/roadmap](https://alkeari.com/roadmap/).

## Mount & Blade II: Bannerlord

- **[Cultured Start Reloaded](https://alkeari.com/projects/cultured-start-reloaded/)**: Bannerlord character creation, overhauled.
- **[Inventory Enhancer](https://alkeari.com/projects/inventory-enhancer/)**: Sorting, filtering and search for Bannerlord's inventory screen, so managing hundreds of items stays fast.
- **[Universal Patch](https://alkeari.com/projects/universal-patch/)**: Gear from twenty different mods stops being a lottery.

## Civilization VI

- **[Custom Distance for Start - Updated](https://alkeari.com/projects/custom-distance-for-start-updated/)**: An update of Jerzat's Custom Distance for Start mod, adding four Advanced Setup options that set the minimum starting distance between civilizations, city-states and the map edge.
- **[No More Petting](https://alkeari.com/projects/no-more-petting/)**: No More Petting removes the Pet the Dog command from scout unit controls in Civilization VI, so a stray click no longer stops your scout to give belly rubs instead of exploring.

## Civilization VII

- **[Tech and Civic Queue](https://alkeari.com/projects/tech-and-civic-queue/)**: Hold Shift and click Technologies and Civics to queue several research targets in order, each with its prerequisites, including Masteries.
- **[Unlock All Mementos Continued](https://alkeari.com/projects/unlock-all-mementos-continued/)**: Every memento slot offers every memento, for any leader, whether you have earned it or not, in single player and in multiplayer lobbies alike.

## Minecraft

- **[Genesis](https://alkeari.com/projects/genesis/)**: See the world before you make it.
- **[GeoGradient](https://alkeari.com/projects/geogradient/)**: Biomes stop being a patchwork.
- **[GeoTectonic](https://alkeari.com/projects/geotectonic/)**: Vanilla's tangle of noodle caves is gone.
- **[Ore Distribution Scanner](https://alkeari.com/projects/ore-distribution-scanner/)**: Stop guessing which Y level to strip-mine.
- **[Ultimine Unchained](https://alkeari.com/projects/ultimine-unchained/)**: FTB Ultimine skips blocks harder than the one you clicked, and charges a point of durability for every block it breaks.

## Palworld

- **[Palpedia Enhancer](https://alkeari.com/projects/palpedia-enhancer/)**: Search, sort and filter the Palworld Palpedia, and clear every unread notification dot with one key instead of opening 150 entries by hand.
- **[Passive Pals](https://alkeari.com/projects/passive-pals/)**: Wild pals stop hunting you down while you are just traveling, and stop bolting the moment you walk near.
- **[Tidy Base Info](https://alkeari.com/projects/tidy-base-info/)**: Palworld's Base Info panel, fixed.
- **[Universal Config Manager](https://alkeari.com/projects/universal-config-manager/)**: Edit every installed mod's settings from one Mod Configs tab in Palworld's options menu: switches, sliders and a page per mod, saved back into each mod's own file.

## Valheim

- **[File Janitor](https://alkeari.com/projects/file-janitor/)**: File Janitor keeps Valheim's BepInEx folder clean: it removes files left behind by uninstalled mods and keeps every mod's config current, backing up each file first.
- **[MultiCraft for SeneaL UI](https://alkeari.com/projects/multicraft-for-seneal-ui/)**: MultiCraft for SeneaL UI lets MultiCraft and SeneaL UI's crafting window work together, so a chosen amount crafts as one batch with one timer.
- **[SmartCraftStorage for SeneaL UI](https://alkeari.com/projects/smartcraftstorage-for-seneal-ui/)**: SmartCraftStorage for SeneaL UI makes SeneaL UI's crafting window show the materials SmartCraftStorage finds in nearby chests.

## Software

- **[Bannerlord Environment Manager](https://alkeari.com/projects/bannerlord-environment-manager/)**: Keep several Bannerlord versions on one machine, each with its own mods and saves, and switch between them from a dropdown.

## Browser extensions

- **[Nexus Mods Assistant](https://alkeari.com/projects/nexus-mods-assistant/)**: Every mod tile on Nexus Mods gets a compatibility verdict for the game version you actually play, so you can filter a catalog page down to what will run and download the survivors in one pass instead of one tab at a time.
